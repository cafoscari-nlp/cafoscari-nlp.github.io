# Ca’ Foscari NLP website

A lightweight, responsive website for https://cafoscari-nlp.github.io with clearly labelled placeholder content.

## Publish

Copy `index.html`, `styles.css`, `.nojekyll`, and the `assets` folder into the root of the existing `cafoscari-nlp.github.io` repository. Keep its existing LICENSE. Commit the files to the branch used by GitHub Pages. The site requires no build tools or external dependencies.

If necessary, check Settings → Pages and select deployment from the main branch, root folder. The existing website is already live, so keep its working Pages settings where possible.

## Edit

Replace placeholder copy in `index.html`. Update colours and layout in `styles.css`. The selected logo is `assets/logo.png`. Contact details, member identities, research themes, and project links are intentionally not invented. The GitHub links point to the existing organization.

Open `index.html` in a browser to preview locally. No installation is needed.
